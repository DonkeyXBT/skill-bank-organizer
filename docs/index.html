RuneLite plugin

Skill Bank Organizer

Opens your bank, files every stack onto a skill page, and tells you what belongs where. You rebuild the tabs by hand — the plugin never drags items.

View on GitHub Plugin source

How it works

1. Scan Open your bank. The plugin reads the live bank container and matches each stack to a skill (and Raids).
2. Check the page Each skill has tools (best owned vs missing), training methods, what you already have, and a rebuild order.
3. Rebuild by hand Drag items into the suggested tab following that order. Placeholders keep the section from collapsing.

Right-click → Send to page

Right-click a bank item and choose Send to Woodcutting (or Raids, Magic, …). That:

  • Opens the matching skill page in the sidebar
  • Writes a Bank Tag so you can search #woodcutting or #raids
  • Highlights those items in the bank while the page is open
It cannot move the item Jagex does not allow plugins to drag bank slots. Send-to-page tags and shows you the destination. You still pull the stack onto the tab yourself.

What each page shows

  • Tools — upgrade path. Marks the best one you already own.
  • Training methods — supplies for that method, have vs need.
  • In your bank — matching stacks from the last scan.
  • Rebuild order — top-to-bottom layout for that tab.

Items can sit on more than one page (maple logs → Woodcutting, Firemaking, Fletching). Leftovers land on Uncategorized.

Raids kits

There is a dedicated Raids page with CoX, ToB and ToA blocks: weapons and armour first, then supplies (overloads, brews, salts, liquid adrenaline).

Install

  1. In RuneLite, click the wrench to open Configuration.
  2. Open Plugin Hub at the bottom of the plugin list.
  3. Search for Skill Bank Organizer and click Install.
  4. Enable it, then open your bank. Scan fills the pages.

The Plugin Hub submission is still in review, so the plugin appears in that list once it is merged.
